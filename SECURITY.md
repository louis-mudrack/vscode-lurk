# Security policy

## Supported versions

Only the latest release of Lurk receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/louis-mudrack/twitch-video-player-vsc-extension/security/advisories/new)
(_Security_ tab → _Report a vulnerability_). You will get an answer within a week.

Things worth reporting include ways for chat messages, emote data or stream content to run code or
inject markup in the webviews, to escape the webview content security policy, or to make the
extension host fetch arbitrary URLs.
