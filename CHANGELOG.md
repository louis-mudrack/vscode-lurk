# Changelog

## 0.1.0

- Twitch livestream player in the Explorer sidebar with quality selection, volume and
  picture-in-picture.
- Audio playback inside VS Code by transcoding Twitch's AAC audio to FLAC in the webview.
- Automatic raid following via Twitch's push socket, with a prepared-raid fallback.
- Read-only chat panel with Twitch and 7TV emotes, badges and moderation (deleted messages,
  timeouts).
- Offline channels start playing automatically when they go live.
